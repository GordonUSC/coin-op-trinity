# coin-op-trinity

A single-page editorial tribute to three lifers of the Chicago coin-op tradition:

- **Eugene Jarvis** — Raw Thrills · *Defender, Robotron, NARC, Cruis'n, Halo: Fireteam Raven*
- **George Gomez** — Stern Pinball · *Tron cabinet, Spy Hunter, Monster Bash, Lord of the Rings, Deadpool, James Bond 007, Pokémon*
- **Joe Kaminkow** — Aristocrat Gaming · *Space Shuttle, Star Wars Trilogy, Apollo 13, Wheel of Fortune slots, NFL slot line*

Three formats — arcade video, pinball, the slot floor — and the Williams / Bally / Midway / Data East spine that runs through all three careers. Includes Eugene's patronage work: the Jarvis College at DePaul, the Eugene Jarvis Auditorium at UC Berkeley, and the inaugural Collegiate Games Challenge with Gay Gaming Professionals.

Built by Gordon Bellamy. One self-contained `index.html` — no build step, no framework. iPhone-first responsive.
